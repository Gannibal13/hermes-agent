# Global Execution Contract System

Сложная задача идёт по контракту, а не по обещаниям. Правила:

1. Каждое обязательное требование — acceptance item (`## [ID]`) со статусом
   и доказательством. Без `Status:`/`Evidence:`/`Asserts:` гейт не запускается.
2. Evidence = исполняемые pytest-nodeid. Гейт выполняет ровно их множество
   свежим прогоном (`-p no:cacheprovider`) и принимает только `PASSED`
   этого прогона. Существующий зелёный тест не засчитывается, если требуемая
   проверка другая, — допиши тест под проверку, а не проверку под тест.
3. Требования не схлопываются: пол `MinEvidenceItems`, наборы nodeid
   попарно различны. 20 требований ≠ «добавил один тест».
4. Задача не сужается при новом промпте: уточнения APPEND'ятся в
   `## Amendments`, контракт без этого раздела не проходит гейт.
5. Финал запрещён, пока хоть один item не PASS: exit 1 + `FINAL FORBIDDEN`.
6. Каждая ветка доказывается контролируемым прогоном: позитив (exit 0) и
   негатив (`--force-open` обязан дать exit 1). Скилл-марктдаун, prose-отчёт
   и «добавил тест» сами по себе доказательством не являются.

## Новый контракт

Скопируй формат из `smart_router_reference.md`: шапка `MinEvidenceItems:`,
блоки `## [ID]`, `## Amendments`. Запуск:

```
python contracts/gate.py --contract contracts/<name>.md
```

Первый инстанс: `smart_router_reference.md` (`MinEvidenceItems: 20`).
Совместимость: `gate_smart_router.py` — тонкая обёртка над `gate.py`.
